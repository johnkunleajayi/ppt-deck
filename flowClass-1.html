2 & 3. What is Salesforce Flow & Business Need

Declarative Automation Engine

Salesforce Flow allows administrators and developers to build complex business logic visually—without writing code.

Capabilities: Create, update, delete, or fetch records; route decisions; post notifications; call external APIs; guide screen users.

The Cost of Manual Work

Consider 500 new Accounts created monthly. Manual task logging requires 3,000+ repetitive clicks.

  • Eliminates human latency and error rates.
  • Enforces standardized business processes.
  • Frees staff to focus on high-value human judgment.

4 & 5. Flow in Action: Manual vs. Automated

Flow serves as the underlying orchestration engine linking business events to downstream tasks.

1. Event Occurs
2. Flow Evaluates Logic
3. Automated Actions
4. Records Updated / Team Notified

Manual Process

Record created → Employee notices → Employee creates Task → Employee sets due date → Employee updates status.

Flow Automated Process

Record created → Flow triggers → Logic evaluates → Task instantly generated & assigned in milliseconds.

6 & 7. Flow Positioning: Apex & Legacy Tools

Flow vs. Apex Code

Flow (Declarative): Clicks-not-code visual builder. Faster time-to-market, easier maintainability.

Apex (Programmatic): Code language used when complex algorithms, high-volume batch processing, or non-supported actions are required.

Golden Rule: "Flow first, code only when necessary."

Legacy Tools Retirement

  • Workflow Rules: Deprecated / Retire state.
  • Process Builder: Deprecated / Retire state.
  • Salesforce Flow: The single, unified declarative automation standard for modern Salesforce professionals.

8 & 9. Flow Architecture & Design Mindset

Before touching Flow Builder, translate business requirements into three architectural questions:

1. What starts it?

The Trigger: An Account record is created, a field updates, or a schedule hits.

2. Is there logic?

Conditions & Decisions: Only run if Account Type = Customer.

3. What should it do?

The Actions: Create a Task, update a related contact, or send an email.

10. Types of Salesforce Flows

Record-Triggered Flow

Runs automatically behind the scenes when a record is created, updated, or deleted.
Focus of today's class.

Screen Flow

Provides a guided user interface with forms, wizards, and interactive screens for users to complete.

Schedule-Triggered Flow

Executes automatically at specified recurring times/dates for a batch of matching records.

Autolaunched Flow

Runs headlessly without a UI; invoked by Apex, REST APIs, or parent Flows.

18 & 19. Summary & Essential Terminology

TRIGGER

What event starts the automation workflow?

ELEMENT

Building blocks (Create, Update, Decision, Get).

ACTION

The operation executed (Create Task, Send Email).

CONDITION

Filter rules governing execution logic.

20. Common Beginner Mistakes

1. Forgetting to Activate

Saving a Flow does NOT make it run. You must explicitly click Activate in Flow Builder.

2. Testing with Mismatched Data

Testing with Type = "Prospect" when your filter requires "Customer" will bypass the Flow correctly—don't mistake this for a bug!

3. Mismapping ID Fields

Mapping Assigned To ID to $Record.Id instead of $Record.OwnerId causes tasks to fail or attach to wrong records.

4. Building Without Planning

Opening Flow Builder before defining "When, What, and Under what conditions" leads to messy logic and rework.
